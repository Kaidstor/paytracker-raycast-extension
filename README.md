# PayTracker Payments — Raycast Extension

Расширение для [Raycast](https://raycast.com/) для быстрого добавления платежей в PayTracker.

## Возможности

- **Create Payment** — создание нового платежа вручную
- **Create from Template** — быстрое создание платежа по заранее настроенному шаблону

## Установка

### 1. Клонирование и установка зависимостей

```bash
cd raycast-extension
pnpm install
```

### 2. Получение API токена

1. Откройте PayTracker в браузере
2. Перейдите в **Настройки** → **API Токены**
3. Нажмите **"Сгенерировать новый токен"**
4. Скопируйте токен

### 3. Настройка расширения

1. Запустите расширение в режиме разработки:
   ```bash
   pnpm dev
   ```
2. В Raycast откройте любую команду расширения
3. При первом запуске откроется окно настроек:
   - **API URL** — URL вашего PayTracker сервера (по умолчанию `https://paytracker.ru`)
   - **API Token** — вставьте скопированный токен

## Команды

| Команда | Описание |
|---------|----------|
| `Create Payment` | Создание платежа с выбором типа, суммы, валюты, сервиса и тегов |
| `Create from Template` | Выбор шаблона и мгновенное создание платежа |

## Разработка

```bash
# Режим разработки с hot-reload
pnpm dev

# Проверка линтером
pnpm lint

# Исправление ошибок линтера
pnpm fix-lint

# Сборка для публикации
pnpm build
```
